# Personal Portfolio Website

A modern, responsive personal portfolio website built with Next.js (App Router), Tailwind CSS, and Framer Motion.

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Features

- **Hero & Bio Section**: Personal introduction with background and coursework
- **Projects Section**: Grid of clickable project cards with dynamic routing
- **Contact Section**: Email and social media links
- **Responsive Design**: Works seamlessly on mobile and desktop
- **Smooth Animations**: Framer Motion animations for scroll-triggered fade-ins

## Tech Stack

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion
